# Mewboard для Herdr

Мод для [Herdr](https://herdr.dev/): задачи Mewboard прямо рядом с агентами. Одна
клавиша открывает список открытых задач проекта, в папке которого ты работаешь, и
передаёт выбранную задачу агенту (Claude Code, Codex…) этого пространства.

Работает с любым оформлением Herdr, в том числе с ProdAdvice; на Windows и macOS.

## Как пользоваться

**Ctrl+Shift+M** (на Mac **Cmd+Shift+M**) — открыть задачи.

| Клавиша | Что делает |
|---|---|
| Enter | вставить задачу в поле ввода агента (не отправляя) |
| Ctrl+Enter (⌘Enter) | отдать задачу агенту сразу |
| Alt+Enter (⌥Enter) | открыть задачу в Mewboard |
| Tab | «Проект» / «Мои задачи» по всем проектам |
| ↑ ↓, ввод текста | выбрать, отфильтровать |
| Esc | закрыть |

Кнопки под списком: «Вставить агенту», «Отдать сразу», «Открыть» и смена статуса —
«В работе», «На проверке», «Готово».

**Какой проект у папки.** Мод берёт корневую папку пространства и ищет проект с
похожим именем (`streetsushi` → StreetSushi, `kdpbot-sites` → kdpbot). Если не
нашёл или нашёл несколько — покажет список проектов; выбор запоминается для этой
папки. Сменить — клик по названию проекта справа вверху.

**Какой агент получает задачу.** Только терминал, где программа сообщает Herdr
статус агента (Claude Code, Codex…): обычная оболочка выполнила бы строки задачи как
команды, поэтому туда мод ничего не вставляет и говорит «Здесь нет агента». Порядок:
агент, в котором был фокус до открытия списка; иначе тот, что запомнил ProdAdvice;
иначе единственный агент пространства. Если агентов несколько, мод попросит кликнуть
в нужного, а не угадывает.

Текст для агента: «Задача KEY-12: название», описание (до 4000 символов) и ссылка
на задачу в Mewboard.

## Установка

Нужны Herdr (откройте его хотя бы раз) и запущенный Mewboard.

```powershell
py install.py            # план: что будет записано
py install.py --apply
```

На macOS — `python3` вместо `py`. Обновление: `--update --apply`, удаление:
`--uninstall --apply`. Установщик не перезаписывает чужой мод с именем `mewboard` и
занятые клавиши (`--skip-conflicting-keys` оставит вашу).

## Подключение к Mewboard

По умолчанию — локальный Mewboard на `http://127.0.0.1:4800` без токена (как его
MCP-сервер). Для другого адреса создайте в установленном моде
`~/.config/herdr-app/mods/mewboard/mewboard.local.json`:

```json
{ "base": "https://mewboard.example.com", "token": "mb_…" }
```

Токен — личный токен Mewboard. Файл ваш: установщик его не трогает и не удаляет.

## Что мод делает и куда ходит

- Читает задачи и проекты (`GET /api/projects`, `GET /api/issues`) и меняет статус
  (`PATCH /api/issues/<KEY>`) только по вашему клику, на адрес выше.
- Вставляет текст через буфер обмена Herdr и возвращает прежний текст через 0,7 с;
  «Отдать сразу» использует `hc send` (вставка и Enter в терминале агента).
- Открывает ссылку на задачу в браузере. Других программ не запускает, файлов вне
  своей папки не пишет; привязки папок хранит в общем состоянии Herdr
  (`mewboard.projects.v1`).
